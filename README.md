This study investigates the use of machine learning techniques for detecting epilepsy through EEG data, focusing on models like Logistic Regression, Random Forest, SVM,  and KNN. The analysis was based on 40 features extracted from EEG recordings of 198 subjects. The process involved data preprocessing and feature selection to ensure effective model performance. The results indicated that selecting a well-defined set of features could maintain high classification accuracy across all models, which helped improve computational efficiency and made the results easier to interpret. Performance was assessed using metrics such as accuracy, precision, recall, F1 score, and AUC , with Logistic Regression and SVM demonstrating strong ability to differentiate between epileptic and normal EEG patterns.  These findings underscore the value of machine learning in enhancing clinical diagnosis and providing continuous monitoring of epilepsy. Ultimately, the study contributes to the expanding field of computational healthcare by emphasizing the integration of machine learning to improve diagnostic precision, support clinical decisions, and promote further research on the real-world application of these methods.
The dataset for the coursework consists of EEG features extracted from a publicly available database of EEG signals (https://www.kaggle.com/datasets/harunshimanto/epilepticseizure-recognition/data).
